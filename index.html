About BWATERY

BWATERY is a simple, effective water intake tracker that helps you stay hydrated by giving you a clear daily goal, a playful bubble that fills as you drink, and gentle reminders so you never forget to hydrate.

🛠️ Tech Stack

  • HTML5 + CSS3 — structure & styling
  • Vanilla JavaScript — all app logic
  • Open-Meteo API — live weather temperature
  • Web Notifications API — hydration reminders
  • Google Fonts — Poppins + Fredoka
  • localStorage — offline data persistence

🌟 Benefits

  • Better focus, energy, and skin health
  • Stops forgetting to drink water
  • Works fully offline — no account needed
  • Simple, distraction-free, and fun
